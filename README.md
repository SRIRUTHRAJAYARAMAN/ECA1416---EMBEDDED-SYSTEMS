# ECA1416---EMBEDDED-SYSTEMS
# Experiment 1 – LED Blinking Using 8051

## Aim

To design and simulate an LED blinking circuit using the **80C51/8051 microcontroller** in **Proteus 8 Professional** using Assembly Language programming.

## Objective

- To understand the basic operation of the 8051 microcontroller.
- To configure an 8051 port pin as an output.
- To control an LED using an 8051 port pin.
- To generate a time delay using Assembly Language.
- To simulate and observe LED blinking in Proteus.

## Software Required

- Proteus 8 Professional
- ASEM-51 / VSM Studio
- 8051 Assembly Language

## Components Required

| Component | Quantity |
|---|---:|
| 80C51 Microcontroller | 1 |
| Crystal | 1 |
| 33 pF Capacitor | 2 |
| LED | 1 |
| 330 Ω Resistor | 1 |
| +5 V Supply | 1 |
| Ground | 1 |

## Circuit Connections

The LED is connected to **P2.0 (Pin 21)** of the 80C51.

| 80C51 Pin | Connection |
|---|---|
| P2.0 – Pin 21 | 330 Ω resistor → LED → GND |
| XTAL1 – Pin 19 | Crystal |
| XTAL2 – Pin 18 | Crystal |
| XTAL1 | 33 pF capacitor → GND |
| XTAL2 | 33 pF capacitor → GND |
| EA – Pin 31 | +5 V |
| RST – Pin 9 | Reset circuit |
| VCC – Pin 40 | +5 V |
| GND – Pin 20 | Ground |

## Assembly Program

```asm
ORG 0000H

START:
    SETB P2.0
    ACALL DELAY

    CLR P2.0
    ACALL DELAY

    SJMP START

DELAY:
    MOV R4,#35

DLY1:
    MOV R3,#255

DLY2:
    DJNZ R3,DLY2
    DJNZ R4,DLY1

    RET

END
```

## Program Explanation

### `ORG 0000H`

Specifies the starting address of the program as `0000H`.

### `SETB P2.0`

Sets P2.0 to logic HIGH and changes the LED state.

### `ACALL DELAY`

Calls the delay subroutine to create a time interval.

### `CLR P2.0`

Clears P2.0 to logic LOW.

### `SJMP START`

Jumps back to the `START` label and repeats the process continuously.

### Delay Subroutine

The delay is generated using nested loops with registers `R4` and `R3`.

```asm
MOV R4,#35
DLY1:
MOV R3,#255
DLY2:
DJNZ R3,DLY2
DJNZ R4,DLY1
RET
```

The `DJNZ` instruction repeatedly decrements the registers and creates the required delay.

## Working Principle

When the simulation starts, the 8051 executes the program from address `0000H`.

1. P2.0 is set HIGH.
2. The LED changes to its ON state.
3. The delay subroutine is executed.
4. P2.0 is cleared LOW.
5. The LED changes to its OFF state.
6. The delay subroutine is executed again.
7. The program jumps back to `START`.
8. The process repeats continuously.

Therefore, the LED continuously blinks.

## Simulation Procedure

1. Open **Proteus 8 Professional**.
2. Create a new schematic.
3. Place the **80C51** microcontroller.
4. Connect the crystal and 33 pF capacitors.
5. Connect the LED to **P2.0 (Pin 21)** through a **330 Ω resistor**.
6. Connect **EA (Pin 31) to +5 V**.
7. Enter the Assembly program in the VSM Studio source-code editor.
8. Build/compile the program.
9. Verify that the assembler reports **0 errors**.
10. Locate the generated `Debug.HEX` file.
11. Double-click the 80C51 in Proteus.
12. Load `Debug.HEX` into the **Program File** field.
13. Set the clock frequency to **12 MHz**.
14. Start the Proteus simulation.
15. Observe the LED blinking continuously.

## Expected Output

The LED connected to **P2.0** should continuously switch between ON and OFF states with a time delay.

**Expected sequence:**

```text
LED ON
   ↓
DELAY
   ↓
LED OFF
   ↓
DELAY
   ↓
LED ON
   ↓
REPEAT
```

## Result

The **LED blinking circuit using the 80C51 microcontroller was successfully designed and simulated in Proteus**. The LED connected to P2.0 continuously blinks according to the delay generated by the Assembly Language program.

## Conclusion

This experiment demonstrates basic **8051 port programming, Assembly Language instructions, subroutine-based delay generation, and Proteus simulation**. The experiment provides a fundamental understanding of controlling an external output device using an 8051 microcontroller.

## Troubleshooting

### Error: `symbol not defined`

Check the spelling and formatting of labels such as:

```asm
START:
DELAY:
DLY1:
DLY2:
```

Make sure every label referenced by `SJMP`, `ACALL`, or `DJNZ` is defined.

### LED does not blink

Check:

- LED polarity.
- 330 Ω series resistor.
- P2.0 connection.
- EA pin connected to +5 V.
- Crystal and capacitors.
- Correct `Debug.HEX` file loaded into the 80C51.
- Clock frequency set correctly.

### HEX file is not generated

Build the Assembly source again and verify that the VSM Studio output shows:

```text
0 errors detected
```

before loading the HEX file into Proteus.
